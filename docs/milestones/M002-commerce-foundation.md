
# M002 Commerce Foundation

## Objective

Establish the first business application for Eraxis and create an integrated Commerce domain on top of the Runtime Platform.

## Scope

### M002-01 Commerce Application Foundation

* Commerce Application Registration
* Commerce Plugin Registration
* Commerce Navigation Integration
* Commerce Routing
* Commerce Landing Page

### M002-02 Product Foundation

* Product Type
* Product Registry
* Product Loader Service
* Product Navigation
* Product Runtime Page

### M002-03 Category Foundation

* Category Runtime Page
